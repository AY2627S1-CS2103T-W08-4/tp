## Product decision and final scope

Serve teaching staff who type commands to maintain student contacts, view a class
and record weekly attendance. Preserve the five released MVP workflows. Add only
student contact correction (`update`) to avoid destructive delete/re-add when a
contact changes. Keep the existing one-group-per-course and one-decision-per-week
contracts and JSON schema. Keep legacy contact compatibility explicit.

Freeze new scope now: no bulk attendance, extra statuses, name/Telegram search,
exports, undo, cloud sync, reminders, archives or multiple sessions per course/week.
Defer membership editing until its attendance-retention semantics can be designed.
Do not add features for line counts. v1.5 is for defect fixes, acceptance testing,
UI clarity and accurate UG/DG; assess any essential behavior change before the
formal freeze. This is an internal scope freeze, not a claim that course freeze
has already started.
